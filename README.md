# Master's-Project
Spring 2026

#### Overview
This project aims to quantify achievement gaps in the post-pandemic period through a two-way fixed effects difference-in-difference model. The analysis focuses on English Language Arts (ELA) performance in New York City public schools. The data used is from the New York City Department of Education, which consists of: </br>
    - School-level ELA test scores </br>
    - School-level poverty rates <br>
A cleaned and merged dataset is available in this repository as "cleaned_school_data_updated,csv". <br>
